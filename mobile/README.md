# Iris pour Android

Iris 1.3 propose ses mises à jour dans l’app. Une première installation manuelle ajoute cette fonction ; les versions suivantes sont annoncées à l’ouverture et dans Réglages → Rechercher une mise à jour. Le téléchargement vérifie le fichier et sa signature, puis Android demande de confirmer l’installation. Le circuit GitHub et la compilation sont décrits dans le [guide du dépôt](../README.md).

Iris 1.2 ajoute, sur chaque conseil et dans le détail de l’historique, « Ajouter à mes à lire MangaTime », puis « Retirer de mes à lire MangaTime ». Au premier ajout, importe le fichier `session-mangatime.json` déjà utilisé par MangaTime Export (également disponible dans Réglages → MangaTime). La session est vérifiée en ligne et chiffrée avec Android Keystore ; elle n’est jamais incluse dans l’APK ni transmise à OpenAI.

Choisis la fiche MangaTime correspondant au conseil avant l’ajout. Le bouton retrouve les ajouts après redémarrage et les répercute dans la bibliothèque Iris. L’annulation concerne les ajouts faits par Iris et vérifie leur état en ligne : une lecture commencée, annotée, notée ou ajoutée à une liste personnalisée est conservée. Une erreur ne vaut jamais confirmation ; le bouton propose d’actualiser l’état avant une nouvelle tentative. Les exports restent lus sans modification. Une nouvelle session est nécessaire si MangaTime expire la connexion.

Iris fonctionne directement sur Android, sans serveur PC, liaison USB ni adresse locale. L’historique et la bibliothèque sont stockés sur le téléphone et consultables hors ligne. Dans Bibliothèque, sélectionne une fois le dossier Android contenant les exports JSON MangaTime. Iris relit le dernier fichier nommé `mangatime-AAAAMMJJ-HHMMSS-….json` au démarrage, au retour et pendant l’utilisation si la dernière vérification remonte à une heure. MangaTime doit y déposer un nouvel export pour que ses modifications soient visibles. Une erreur conserve la dernière copie valide.

Dans les réglages (icône en haut à droite), enregistre ta clé API OpenAI. Elle est chiffrée par Android Keystore, jamais intégrée à l’APK et jamais renvoyée à Flutter après enregistrement. Les conseils et la recherche Web appellent directement OpenAI par Internet et sont facturés sur ton compte API. La recherche utilise la bibliothèque synchronisée lorsqu’elle est disponible ; des éléments de celle-ci sont transmis au modèle pour personnaliser les conseils. Sans clé, le catalogue MangaDex reste accessible par Internet. Aucun abonnement ChatGPT ne remplace la facturation de l’API.

Choisis 1 à 5 propositions. Conseil cherche toujours des titres hors de toute ta bibliothèque. « Affiner la recherche » propose l’origine (manga japonais, manhwa coréen ou manhua chinois), dix genres cumulables, la publication (terminée ou en cours) et la longueur (1 à 50, plus de 50 ou plus de 100 chapitres). Les valeurs inconnues ou contradictoires ne confirment pas un filtre. Les filtres sont obligatoires dans les deux modes. Le mode à la lettre impose aussi tous les critères de la demande ; le mode indicatif permet une piste exploratoire annoncée. Les propositions déjà enregistrées dans l’historique local sont exclues des nouvelles sélections.

Les filtres sont appliqués uniquement après validation. Fermer le panneau annule les modifications en cours. Les filtres actifs se retirent directement depuis la page. Le bouton de recherche reste visible pendant le défilement, et une envie vide laisse Iris proposer une lecture libre.

Historique regroupe les recherches réelles par date. Chaque carte conserve la demande, l’heure et tous les titres proposés ; deux essais d’une même demande restent distincts. La recherche retrouve une demande ou un titre. Toucher un titre ouvre directement son conseil, ses réserves et les réglages d’origine. Les anciens résultats à une seule œuvre, les abstentions et les erreurs restent consultables. L’actualisation est disponible par le bouton ou en tirant la liste vers le bas ; une erreur de connexion conserve les recherches déjà chargées.

Dans « Où lire », le champ titre suggère les œuvres proposées dans tes conseils et celles de ta bibliothèque synchronisée (ou de la bibliothèque initiale hors ligne). Les titres alternatifs disponibles dans les conseils sont aussi reconnus. Toucher une suggestion remplit le titre et place le curseur dans le chapitre, sans modifier un chapitre déjà saisi ni démarrer de recherche. Tu peux toujours saisir un autre titre librement. Indique un chapitre ou une plage de 25 chapitres maximum, puis lance la recherche. Avec une seule œuvre trouvée, Iris enchaîne automatiquement ; un choix reste proposé pour les homonymes.

Tous les liens de chapitre forment une seule liste, avec leur langue et leur site. Les chapitres MangaDex sans pages sont exclus. Les liens externes proposés par la recherche Web sont ouverts directement sur le téléphone pour vérifier le titre, le numéro exact et la présence d’un lecteur ou d’un achat du chapitre individuel. Les pages de série, les simples décomptes et les pages dont l’accès ne peut être confirmé ne sont pas affichés. Un chapitre vendu individuellement porte la mention « Achat du chapitre ». Les chapitres sans lien confirmé sont signalés explicitement, sans conclure qu’ils n’existent pas. Certains lecteurs uniquement accessibles via JavaScript ou protégés contre l’accès automatisé peuvent ne pas être confirmés. La recherche Web reçoit les titres publics, les numéros demandés et les URL publiques de publication ; elle est facturée via la clé configurée sur le téléphone.

Les APK distribuées sur GitHub ne contiennent aucune bibliothèque ni recherche personnelle. Les mises à jour conservent la base locale existante. L’APK locale de transition conserve aussi les anciennes données initiales sur le téléphone avant la première mise à jour publique. Une recherche interrompue par l’arrêt complet de l’app est signalée comme telle au prochain lancement. Désinstaller l’app efface ses données et sa clé ; installe les mises à jour par-dessus.

## Compilation

Flutter 3.41 / Dart 3.11, JDK 17, Android SDK 36 et Python 3.11 sont nécessaires sur la machine de compilation. Chaquopy 17.2 embarque Python 3.11 et le même moteur que `prototype`, sans service HTTP. Python 3.11 peut être installé normalement (détection automatique) ou décompressé dans `mobile/.tools/python311`. Le dossier `.tools` est réservé à la compilation et exclu de l’APK. Les modules et les seules données initiales nécessaires sont copiés par la tâche Gradle `prepareIrisPython` ; les fichiers de diagnostic, le serveur PC et ses variables d’environnement ne sont pas embarqués.

Depuis `mobile` : `flutter build apk --release`. L’APK universelle prend en charge ARM 32 bits, ARM 64 bits et x86_64, Android 7.0 minimum. La signature actuelle permet de mettre à jour la première APK personnelle. Il faut une signature de distribution propre avant une publication sur un store.
